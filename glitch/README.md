# 💖 Guide de Déploiement sur Glitch (Depuis votre Téléphone)

Voici comment déployer l'application **Charobidy baeko** gratuitement en 3 minutes sur **[Glitch.com](https://glitch.com)** :

---

### 📱 Étape 1 : Créer un projet Glitch
1. Ouvrez votre navigateur sur votre téléphone ou PC et allez sur **[glitch.com](https://glitch.com)**.
2. Créez un compte gratuit (ou connectez-vous avec Google / GitHub).
3. Cliquez sur **« New Project »** (Nouveau projet) ➔ choisissez **« gltich-hello-node »** (ou n'importe quel projet Node).

---

### 📂 Étape 2 : Coller les fichiers
Dans le menu de gauche de Glitch, créez ou remplacez les fichiers suivants en copiant-collant le code :

1. **`package.json`** ➔ Collez le contenu de `package.json`.
2. **`server.js`** ➔ Collez le contenu de `server.js`.
3. Cliquez sur **« New File »** ➔ tapez `public/index.html` ➔ Collez le contenu de `public/index.html`.
4. Cliquez sur **« New File »** ➔ tapez `public/style.css` ➔ Collez le contenu de `public/style.css`.
5. Cliquez sur **« New File »** ➔ tapez `public/app.js` ➔ Collez le contenu de `public/app.js`.

---

### 🚀 Étape 3 : Lancer l'application
1. Glitch installe automatiquement `express` et `cors` dès que vous sauvegardez `package.json`.
2. Cliquez sur le bouton **« Preview »** (ou **« Share »** ➔ **« Live Site »**).
3. Vous obtenez votre lien public gratuit en HTTPS :
   `https://nom-de-votre-projet.glitch.me`

---

### 💕 Utilisation par le couple
- **Nacia** et **Charobidy** ouvrent le même lien sur leurs téléphones.
- Chacun choisit son profil (*Nacia* ou *Charobidy*).
- Dès qu'un rendez-vous est scellé, il est écrit de manière sécurisée dans `data/dates.json` sur le serveur Glitch et apparaît en temps réel sur les deux téléphones dans le **Tableau de bord** !
